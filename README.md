# PetBazarBangladesh — GitHub Pages Starter

A responsive static prototype for a Bangladesh pet marketplace.

## Categories
- Cats and dogs: buy, sell, and free adoption
- Pet accessories: new and used items (food, toys, shampoo, collars, beds, grooming, etc.)
- Used accessory listings include a field for condition details

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload the contents of the `PetBazarBangladesh` folder to the root of your GitHub repository.
3. In Settings → Pages, select Deploy from a branch → `main` → `/(root)`.

## Important prototype limitations
This is a static front-end demo. Listing previews are not saved or published. Login, database, image uploads, messaging, moderation, and real payments are not connected. Do not collect sensitive information or accept payments through this demo. A secure backend is required before launch.
