# PetBazarBangladesh — GitHub Pages starter

## Publish free on GitHub Pages
1. Sign in at https://github.com and create a **public** repository named `petbazarbangladesh`.
2. Extract this ZIP on your phone or computer.
3. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root (do not upload only the ZIP).
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main`, folder `/(root)`, and click **Save**.
7. Wait for deployment, then use **Visit site** in Pages settings.
8. The URL usually looks like `https://YOUR-USERNAME.github.io/petbazarbangladesh/`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Important limitations
- Listings shown are sample/demo content, not verified real listings.
- The post form is only a preview; it does not save or publish listings.
- Login, database, image uploads, moderation, and messaging are not connected.
- Payments are not integrated. Do not collect real payments using this prototype.
- GitHub Pages serves static files and does not provide server-side payment verification.

## Future payment plan
Keep payments disabled for the first public demo. Later, choose a Bangladesh payment provider, apply for a merchant account, use its sandbox/test environment, and verify transactions on a trusted server-side backend before enabling live payments. Never put secret API keys in `index.html` or public JavaScript files.
